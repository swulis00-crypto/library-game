## 1. 제품 개요

### 1.1 제품명
**책길 탐험대** — 고전게임으로 배우는 도서관 청구기호

### 1.2 제품 설명
초등학교 고학년과 중학생이 도서관 서가에서 원하는 책을 스스로 찾을 수 있도록, 친근한 고전 아케이드 게임 6종(미로, 정렬 퍼즐, 스페이스 인베이더, 벽돌 깨기, 스네이크, 두더지 잡기)을 통해 **한국십진분류법(KDC) 제6판**, **이재철 저자기호표**, **서가 배열 규칙**을 직관적이고 재미있게 익히는 반응형 웹 애플리케이션이다.

### 1.3 해결하려는 문제
- 청구기호(분류번호 + 저자기호)는 아이들에게 낯선 암호처럼 보여 서가 앞에서 책을 포기하는 경우가 많다.
- 분류번호를 숫자로만 외우면 "주제 → 번호" 연결이 되지 않는다.
- 저자기호의 생김새와 "번호가 같으면 가나다순"이라는 배열 규칙을 체험할 기회가 없다.
- 도서관 이용 교육이 설명 위주라 아이들의 참여도가 낮다.

### 1.4 제품 비전
아이들이 청구기호를 "책의 주소"로 받아들이고, 게임에서 익힌 규칙으로 실제 서가에서 책을 찾아내는 성공 경험을 하게 한다.

## 2. 목표와 성공 기준

### 2.1 학습 목표
1. KDC 10개 큰 숫자(000~900)와 대표 주제를 연결한다.
2. 주제 설명을 읽고 알맞은 분류번호(세부 분류 포함)를 고른다.
3. 분류번호가 작은 순서, 소수점 비교(813.6 < 813.62 < 813.7)를 안다.
4. 저자기호가 **성 + 이름 번호 + 제목 첫소리**로 이루어졌음을 안다. (직접 만들 줄은 몰라도 된다. 번호표는 사서가 쓴다.)
5. 번호가 같으면 저자기호 가나다순, 그다음 1권·2권(v.1, v.2) 순서로 꽂힌다는 것을 안다.
6. 틀린 문제의 해설(배움 카드)을 읽고 혼동하기 쉬운 영역을 구별한다.

### 2.2 제품 목표
- 아이가 어른의 설명 없이 시작 화면부터 게임, 결과까지 스스로 진행할 수 있다.
- 매번 다른 문제가 나와 여러 번 해도 지루하지 않다.
- 틀려도 혼나는 느낌이 아니라 "힌트를 보고 다시 해보자"는 느낌을 준다.
- PC(노트북), 태블릿, 휴대폰에서 모두 조작할 수 있다.
- 사서가 우리 도서관 책을 등록하면 그 책이 문제에 반영된다.

### 2.3 성공 기준
- 6개 게임 모두 스크롤 없이 문제와 게임판이 한 화면에 보인다(노트북 1366×768, 125% 배율 포함).
- 휴대폰 세로에서 게임판이 조작 패드에 가려지지 않고, 가로 모드 안내가 있다.
- 자동 생성 문제 1,000개 이상을 검사했을 때 정답 순서 오류가 0건이다.
- 이용자 식별 정보가 브라우저와 서버 어디에도 저장되지 않는다.

## 4. 핵심 원칙 (v2에서 확정)

1. **개인정보를 받지도, 남기지도 않는다.** 이름·별명 입력 없음, 순위표 없음, 점수 저장 없음. 브라우저에 남는 것은 사서가 등록한 도서/문제 데이터와 소리 설정뿐이다. 캐릭터와 "오늘 모은 별"은 새로고침하면 사라진다.
2. **정답은 읽어서 찾는다.** 정답 오브젝트를 색이나 모양으로 구분하지 않는다. (v1에서 외계인·두더지·벽돌의 정답이 다른 색이었던 문제를 제거)
3. **저자기호는 만들지 않고 읽는다.** "이 책의 저자기호를 만들어라" 유형은 출제하지 않는다. 구성 알기와 꽂히는 순서만 묻는다.
4. **틀리면 바로 알려준다.** 게임을 멈추지 않는 짧은 힌트(토스트)와, 스테이지가 끝나면 "왜 그런지" 설명 카드를 보여준다.
5. **힌트·설명은 게임판과 문제를 가리지 않는 자리에 둔다.**

## 5. 기능 요구사항

### 5.1 공통 흐름
- 시작 화면: 마스코트 '책벌레 북이' 인사말, 캐릭터(동물 8종) 선택, [게임 시작] / [먼저 배우기]
- 게임 선택: 6개 카드(아이콘, 한 줄 설명, 배우는 것), 난이도 토글(🌱 쉬움 / 🔥 도전), 오늘 모은 별·플레이 횟수·최고 콤보
- 게임 아레나: 점수·시간·하트·콤보 HUD, 문제 카드, 게임판, 터치 컨트롤, 3·2·1·출발 카운트다운
- 정답 처리: 점수 + 연속 정답 콤보 보너스(최대 +100), 떠오르는 글자·파티클·효과음
- 오답 처리: 감점, 콤보 초기화, 힌트 토스트, 오답 노트 기록
- 스테이지 클리어: 정답과 해설을 담은 카드, [다음 문제] 버튼(7초 후 자동 진행)
- 결과: 별점(최대 3개: 100% = 3, 60% 이상 = 2, 1개 이상 = 1), 꽃가루, 점수/맞힌 문제/최고 콤보, 틀린 문제 배움 카드, [다시 도전] / [다른 게임] / [배움터]
- 나가기: 게임 일시정지 후 확인. 다른 탭/앱으로 벗어나면 자동 일시정지 + [계속하기]
- 배움터: KDC 10가지, 청구기호 뜯어보기, 저자기호 구성, 책꽂이 순서 5규칙

### 5.2 게임별 요구사항

| 게임 | 원작 | 학습 목표 | 핵심 규칙 | v2 재미 요소 |
|---|---|---|---|---|
| 🧭 미로 탈출 | 팩맨 | 주제 → 분류번호 | 힌트에 맞는 번호 책을 먹으면 출구가 열림. 유령에 닿으면 하트 -1, 출발점으로 | 별 조각 모으기, 큰 별(7초간 유령 잡기 +50), 출구 화살표, 20초 후 정답 반짝임(쉬움), 유령은 책 근처를 피함 |
| 📚 책꽂이 정리 | 정렬 퍼즐 | 분류번호 → 저자기호 가나다 → 권차 | 책을 끌어 옮기거나 두 권을 차례로 눌러 교환 후 [확인!] | 칸마다 ✓/✗ 즉시 표시, 3회 실패 시 정답 순서 공개 후 다음 문제 |
| 👾 외계인 격퇴 | 스페이스 인베이더 | 주제별 분류번호 빨리 찾기 | 목표 번호 외계인만 격추. 다른 외계인 격추 시 하트 -1 | 모든 외계인 같은 색, 탭한 자리로 이동+발사, 도전 모드 폭탄 |
| 🧱 벽돌 깨기 | 알카노이드 | 000~900 백 자리 구별 | 미션 번호대 벽돌은 1타, 다른 벽돌은 2타. 다른 벽돌 첫 타격 시 "이 번호는 ○○" 안내 -10 | 콤보, 남은 개수 안내, 탭/스페이스로 발사 |
| 🐍 책벌레 뱀 | 스네이크 | 청구기호 오름차순 | 작은 번호부터 차례대로 먹기. 순서가 틀리면 -30 + 힌트. 몸에 부딪히면 하트 -1, 몸이 3칸으로 | 다음 목표 반짝임+"다음!", 먹을수록 2칸 성장, 워프, 스와이프 조작 |
| 🔨 두더지 팡팡 | 두더지 잡기 | 저자기호 구성 알기 & 꽂히는 순서, 주제 → 번호 | 팻말을 읽고 정답 두더지만 타격. 3번에 1번은 정답 두더지 보장 | 모든 두더지 같은 색, 콤보, 뿅망치 커서. 문제 유형: 성이 ○인 기호 / ○○에서 성·번호·첫소리는? / 제목이 ㅂ 소리로 시작하는 책 / 맨 앞에 꽂히는 기호 / ○ 바로 다음에 꽂히는 기호 / 주제의 분류번호 |

### 5.3 문제 출제
- 한 판 문제 수: 미로 3, 책꽂이 3, 외계인 5, 벽돌 3, 뱀 3, 두더지 5
- 구성: 사서가 등록한(또는 기본) 문제 최대 60% + KDC 세부 분류표·도서 목록 기반 자동 생성 문제. 같은 정답은 한 판에 한 번만.
- 난이도: 쉬움(정수 분류번호, 선택지 4개, 느린 속도) / 도전(소수점·권차 포함, 선택지 6개, 빠른 속도, 폭탄 등)
- 자동 생성 정렬 규칙: 분류번호 숫자 비교 → 저자기호 가나다(ko) → 권차 숫자

### 5.4 사서 선생님 화면
- 숫자 4자리 잠금(기본 1234, 코드에서 변경)
- 도서 자료 관리: 등록(제목, 저자, 분류번호, 저자기호, 청구기호, 서가 위치, 게임 단서), 삭제, 기본 16권 복원. 등록한 책은 미로·책꽂이·두더지 문제에 자동 반영
- 문제 검토: 게임별 등록 문제 수 확인, 초기화
- 백업·복원: 도서·문제 데이터 JSON 내보내기/가져오기 (학생 정보 없음)

### 5.5 화면·입력 대응
- PC/노트북(901px 이상): 게임판 + 오른쪽 문제 카드 2열, 힌트 토스트는 문제 카드 아래. 게임판 높이를 화면 높이에 맞춰 스크롤 없음
- 태블릿(641~900px): 세로 스택, 터치 패드 노출
- 휴대폰 세로(640px 이하): 상단 정보판 한 줄 압축, 문제는 하단 고정 패드 옆, 힌트는 화면 맨 위, "가로로 돌리면 글씨가 커져요" 안내, 전체 화면 오버레이
- 휴대폰 가로: 게임판 화면 꽉 채움, 패드는 양옆 반투명
- 입력: 키보드(방향키/WASD/스페이스), 마우스, 터치 패드, 스와이프/탭(미로·뱀), 드래그(책꽂이)
- 게임판 안 글자 크기: 번호 15~23px 이상(휴대폰 축소 고려)

### 5.6 공유
- 오픈그래프 이미지(1200×630)와 og/twitter 메타 태그로 링크 미리보기 제공
